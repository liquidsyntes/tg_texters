# Discipline of Senses: статьи и бот

Здесь лежит шаблон статей и бот для подготовки двух языковых версий. Бот принимает статью Telegram в личном чате, сохраняет её структуру и фотографии, переводит текст, отправляет архив с двумя HTML-страницами на вычитку и после подтверждения загружает их на статический хостинг. Пост в канал бот не отправляет. Владелец выбирает подготовленный пост через inline-режим Telegram и отправляет его сам.

Исходные демонстрационные страницы: `ru.html` и `uk.html`. Оформление: `style.css`, `brand-logo.png`, `fonts/`. Кнопки копирования используют `article.js`; скрипт подключается только к страницам, где есть такие кнопки. Шрифт Huninn хранится локально.

## Требования

- Python 3.11 или новее. Сторонние Python-пакеты не нужны.
- Бот Telegram, созданный через @BotFather. Включите ему inline-режим командой `/setinline` в @BotFather.
- Для перевода выберите OpenRouter с `OPENROUTER_API_KEY` **или** установленный и авторизованный OpenCode CLI. OpenCode v2.1.4 установлен в WSL на этом компьютере. Для входа в этой версии выполните `opencode auth login` и выберите OpenCode Console или другой нужный провайдер. Бот и CLI должны работать под одним системным пользователем, имеющим доступ к авторизации.
- Для загрузки через SFTP нужен `psftp` (PuTTY) и ключ формата `.ppk`. На этом компьютере `psftp` уже доступен.

## Настройка

Передайте процессу переменные из `.env.example`. В этом рабочем каталоге `.env.local` уже содержит параметры указанного SFTP-хостинга. Создайте бота в @BotFather, включите `/setinline` и заполните `TELEGRAM_BOT_TOKEN` в `.env.local`. Если не знаете свой числовой Telegram ID, выполните `set -a; . ./.env.local; set +a; python3 -m disense.bot owner-id` и отправьте боту показанную одноразовую команду. Внесите полученный `TELEGRAM_OWNER_ID` в `.env.local`, затем запустите `set -a; . ./.env.local; set +a; python3 -m disense.bot`. Файл `.env.local` исключён из Git. Бот отвечает только владельцу в личном чате, а в inline-режиме выдаёт статьи только ему. Не отправляйте токен боту сообщением.

Для текущего хостинга уже настроены:

- `PUBLIC_BASE_URL=https://tgmons.online/static`;
- SFTP-подключение к `ubuntu@54.39.231.150:22`, каталог `/var/www/static/`;
- путь к указанному `.ppk` и закреплённый отпечаток сервера, сверенный с `known_hosts` на этом компьютере.

Файлы статьи будут размещаться прямо в `/var/www/static/` как `<id>-ru.html` и `<id>-uk.html`. Сопутствующие изображения, CSS, шрифты и значок попадут в `<id>-assets/`. Ссылки между двумя версиями и пути к изображениям генерируются автоматически. Для локальной разработки вместо SFTP можно задать абсолютный `PUBLISH_TARGET` и оставить `SFTP_HOST` пустым.

Для OpenCode задайте `OPENCODE_VERSION=v1` или `v2` и, если требуется, `OPENCODE_BIN`. Сейчас выбран v2. Модель указывается в формате `provider/model`, который показывает `opencode models`. Для OpenRouter используйте точный ID модели из его каталога. Авторизация OpenCode на этом компьютере выполнена; короткий перевод бесплатной моделью проверен.

Бот использует long polling. Если у него уже настроен webhook, его нужно отключить перед запуском. Рабочие черновики, настройки и изображения сохраняются в `DISENSE_DATA_DIR` (по умолчанию `./data`). На этом компьютере установлен пользовательский сервис WSL `disense-bot.service` из `deploy/`: он запускается вместе с WSL, статус можно проверить командой `systemctl --user status disense-bot.service`, перезапустить после изменений командой `systemctl --user restart disense-bot.service`. Не запускайте второй экземпляр вручную одновременно с сервисом. Токен и данные владельца хранятся только в исключённом из Git `.env.local`.

## Работа со статьёй

1. В личном чате отправьте боту статью Telegram или обычный текст. Первое оформление заголовком в статье становится заголовком веб-страницы. Обычный текст тоже принимается, но заголовок страницы тогда будет общим.
2. Выберите язык оригинала. Бот скачает фотографии, переведёт текст на второй язык и отправит ZIP с двумя HTML-файлами, стилями и изображениями для проверки.
3. Проверьте перевод и обе страницы. При необходимости смените модель и нажмите «Повторить перевод» либо исправьте исходную статью и пришлите её заново. Нажмите «Подтвердить загрузку», когда результат готов. До этого шага ничего не отправляется на хостинг.
4. После загрузки бот пришлёт ссылки и кнопку выбора канала. Выберите свой канал и подготовленный inline-результат, затем отправьте пост сами. В начале Telegram-поста будут две строки из 26 подчёркиваний, между ними текст `ви можете читати текст у зручному` с переносом перед `форматі на | РУС | УКР | мовами...`. Только `РУС` и `УКР` будут ссылками на соответствующие HTML-версии. Далее идёт исходная статья без изменений. Две URL-кнопки под постом останутся.

Команды: `/provider openrouter`, `/provider opencode`, `/model <ID>`, `/status`, `/help`. При смене провайдера модель сбрасывается, чтобы не использовать ID от другого сервиса. Выбор действует на следующие статьи.

Бот сохраняет исходное содержание без литературной правки. Перевод нужно вычитать перед загрузкой. Поддерживаются абзацы, заголовки, выделение текста, ссылки, списки, цитаты, разделители, фотографии с подписями, URL-кнопки внутри текста и отдельными рядами, кнопки копирования. Telegram-специфические действия кнопок, например `callback_data`, не работают на обычной HTML-странице: бот сообщит об этом, не публикуя неполную страницу. Размер скачиваемой фотографии ограничен обычным Telegram Bot API до 20 МБ.

## Проверка

`python3 -m unittest discover -s tests -v`

Тесты используют примеры статей и поддельный Telegram API, поэтому не расходуют деньги на модели и не отправляют сообщения в канал. Перед реальным использованием нужно проверить полный проход на настоящей статье Telegram, настройках выбранной модели и вашем хостинге.
